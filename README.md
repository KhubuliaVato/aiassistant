# 1Flow AiAssistant

**1Flow AiAssistant** — Windows-ის დესკტოპ პროგრამა სიახლეების გუნდისთვის (1TV): ვიდეოების სწრაფი დამუშავება, ვერტიკალიზაცია, მონტაჟი, AI ფონი, სახის დაბუნდოვნება, ხმის ჩაწერა და სხვა — ერთ ადგილას.

## შესაძლებლობები

- **გავერტიკალურება** — ვიდეო → 9:16, ქვედა ტიტრი, ლოგო, Intro/Outro
- **მინი მონტაჟი** — ჭრა, დაჭრა, ექსპორტი
- **AI ფონი** — ადამიანის გამოჭრა და ვირტუალური ფონი (RVM / MediaPipe)
- **სახის დაბუნდოვნება** — სახეების ავტომატური აღმოჩენა და დაბურვა
- **ხმის ჩაწერა** — Voice-over მიკროფონიდან
- **A/B მონიტორი** — ორი ვიდეოს შედარება
- **გადმოწერა** — YouTube / Facebook / TikTok (yt-dlp)
- **Live Clipper** — პირდაპირი ეთერიდან კლიპების ამოჭრა
- **ბრენდ-კიტი** და **მედია ბიბლიოთეკა**
- მუქი / ღია თემა

## მოთხოვნები

- Windows 10/11 (x64)
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- Python 3.10+ (AI ფუნქციებისთვის: ფონი, სახის დაბუნდოვნება)
- ინტერნეტი პირველ გაშვებაზე

## პირველი გაშვება

დიდი ფაილები პროგრამასთან ერთად არ მოდის. პირველ გაშვებაზე პროგრამა თვითონ ჩამოტვირთავს და დააყენებს, პროგრესის ჩვენებით:

| კომპონენტი | ზომა (დაახლ.) |
|---|---|
| ffmpeg | ~80 MB |
| yt-dlp | ~18 MB |
| AI მოდელები (RVM, YuNet, selfie segmenter) | ~20 MB |
| Python პაკეტები | იცვლება |

ყველაფრის განახლება/გადაყენება შეიძლება **სეთინგებიდან**. მონაცემები ინახება `%LOCALAPPDATA%\1Flow`-ში.

## აწყობა წყაროდან

```bash
dotnet build AiAssistant.csproj -c Release
```

შედეგი: `bin\Release\net10.0-windows\1FlowAiAssistant.exe`
